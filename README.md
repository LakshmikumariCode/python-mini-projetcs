  # Marks Analyzer
A simple Python program to calculate and analyze student marks.

## What it Does
- Calculates total, average, highest, and lowest marks
- Counts how many students passed and failed

## Skills Demonstrated
- Python basics: loops, conditionals, lists
- Problem-solving

## How to Run
1. Open the file `project1_marks_analyzer.py` in Python 3
2. Run the code
3. Modify the `marks` list to test with different data.
